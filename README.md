# SolarOptimization
Using two panels to smooth out the power output
--------------------------------------------------------

In this project, I will be using a stepper motor to switch between a mono and polycrystalline solar panels. This is so I can lower power inconsistencies by switching to the panel with a higher MPP on the weather. As monocrystalline has lower power drops than the polycrystalline when cloudy, we can switch to that when the P&O specs are better, and vice versa. We would be using a stepper motor to physically rotate between the panels while using a passive diode system to ensure seamless switching. 

Some secondary objectives include:
 *  Solar tracking.
 *  Using a BJT transistor system rather than the passive diode system.
