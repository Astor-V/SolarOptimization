# SolarOptimization
Using two panels to smooth out the power output


--------------------------------------------------------

In this project, we will be using a stepper motor to switch between a mono and polycrystalline solar panels. This is so we can lower power inconsistencies by switching to the panel with a higher MPP based on the current weather conditions. As monocrystalline potentially has lower power drops than the polycrystalline when cloudy, we can switch to that when the P&O specs are better, and vice versa. We would be using 3 stepper motor to physically rotate between the panels as well as angling them. To assist the power transfer we are using a passive diode system to ensure seamless switching. 

Some secondary objectives include:
 *  Solar tracking.
 *  Using a BJT transistor system rather than the passive diode system.
